SECCIÓN 1 - Licencias y modelos

*Software libre(FSF): El software respeta la libertad y autonomía de los usuarios y ofrece 4 libertades esenciales que son las de usar, modificar, redistribuir copias y redistribuir cambios.

*Código abierto(OSI): El desarrollo colaborativo produce código técnicamente superior y acelera la innovación. Para la Free Software Foundation de Richard Stallman, la terminología «código abierto» oculta el verdadero debate: el derecho ético a controlar la tecnología en lugar de que la tecnología te controle a ti.

*Software propietario: Niega todas estas libertades. No permite auditar vulnerabilidades por cuenta propia, adaptarlo a necesidades específicas ni redistribuirlo libremente.

El código libre no significa que sea gratuito, esta confusión se debe al inglés ya que se llama "free code".
Que un código sea libre habla más que nada sobre la postedad que tiene el usuario sobre sus libertades de uso.

Una práctica edición Community se trata de una versión de código abierto con una licencia libre, mientras que una edición enterprise se trata de un modelo comercial desarrollado sobre la base comunitaria.


SECCIÓN 2 - Fichas técnicas

1. ERP Libre: Odoo Community
    - Licencia exacta: licencia LGPLv3.
    - Versión vigente: Odoo 17.0.
    - Lenguaje del servidor: Principalmente en Python.
    - SGBD compatibles: PostgreSQL (versión 13 o superior)
    - Modalidad: Instalación local
    - Módulos principales: Ventas, Facturación básica, Gestión de Proyectos, etc...
    - Requisitos: 2 vCPU, 2-4 GB de RAM para equipos pequeños.
    - Bibiografía: https://www.skysize.io/es/blog/guias-5/cuanto-cuesta-odoo-en-2026-el-desglose-completo-31

2. ERP Propietario: Microsoft Dynamics 365
    - Licencia exacta: Propietaria comercial Microsoft.
    - Versión vigente: Versión Cloud 2024 Release Wave 1 / Wave 2.
    - Lenguaje del servidor: Lenguaje AL.
    - SGBD compatibles: Microsoft Azure SQL Database.
    - Modalidad: SaaS Cloud nativo.
    - Módulos principales: Gestión financiera y contable, Gestión de proyectos y costes, etc...
    - Requisitos: Cliente web accesible mediante navegador moderno.
    - Bibiografía: https://learn.microsoft.com/es-es/dynamics365/business-central/

3. CRM Libre: SuiteCRM
    - Licencia exacta: GNU AGPLv3.
    - Versión vigente: SuiteCRM 8.6 / 8.x.
    - Lenguaje del servidor: PHP.
    - SGBD compatibles: MariaDB.
    - Modalidad: On-Premise, despliegue en servidor web propio / hosting Apache/Nginx o Docker.
    - Módulos principales: Cuentas, Contactos, Oportunidades y Pipeline de ventas, etc...
    - Requisitos: Servidor web Linux, 2 vCPU, 4 GB de RAM, extensiones PHP estándar activadas.
    - Bibiografía: https://acumbamail.com/registrate/?refered=251803&utm_term=&utm_content=

4. CRM Propietario: Salesforce Sales Cloud
    - Licencia exacta: Propietaria comercial por suscripción por usuario.
    - Versión vigente: Lightning Platform.
    - Lenguaje del servidor: Apex.
    - SGBD compatibles: Infraestructura de datos propietaria de Salesforce.
    - Modalidad: 100% Cloud SaaS.
    - Módulos principales: Lead & Opportunity Management, Pipeline Inspection, etc...
    - Requisitos: Navegador web moderno con soporte JavaScript/HTML5 en escritorio.
    - Bibiografía: https://www.salesforce.com/products/sales-cloud/


SECCIÓN 3 - Fe de erratas del tema

- Primer fallo
    En el tema menciona a Odoo como un ERP libre, cuando este no es 100% un software libre desde hace ya varios años, sino que funciona como un modelo mixto.

- Segundo fallo
    SuiteCRM no fue desarrollado por la comunidad SugarCRM, sino que nació como un fork independiente impulsado por la empresa británica SalesAgility.
